원그로브 화재시 소방시설 연동로직 체험 시뮬레이터 — 웹서버 배포 안내
==============================================================================

■ 구성
  index.html            시뮬레이터 본체 (외부 라이브러리 없음, 단일 파일)
  audio/bell.mp3|.webm        주경종 · 지구경종 음원
  audio/siren.mp3|.webm       싸이렌 (유수검지장치 · 가스계 연동) 음원
  audio/pa-fire.mp3|.webm     화재시 안내방송 (싸이렌 5초 + 멘트 + 싸이렌 5초)
  audio/pa-siren-3s.mp3|.webm 안내방송 파일을 못 읽을 때 쓰는 대체 싸이렌
  README.txt            이 문서

■ 설치
  폴더 전체를 웹서버 디렉터리에 그대로 올리면 끝입니다.
  index.html 과 audio/ 폴더의 상대 위치만 유지하면 하위 경로에 두어도 동작합니다.
    예) https://사내주소/fire-sim/index.html
        https://사내주소/fire-sim/audio/bell.mp3
  별도 빌드·설치 과정이나 서버측 프로그램은 필요 없습니다.

■ 웹서버 설정 확인
  · audio/*.mp3 가 audio/mpeg 로 서비스되는지만 확인하면 됩니다(대부분 기본 설정).
  · webm MIME 설정이 없어도 mp3 로 자동 대체되므로 문제되지 않습니다.
  · HTTPS 를 권장합니다. 일부 모바일 브라우저는 http 페이지에서 오디오·음성합성
    기능을 제한합니다.

■ 브라우저·모바일 동작 특성 (정상 동작입니다)
  1) 첫 소리는 화면을 한 번 터치(클릭)한 뒤부터 납니다.
     브라우저의 자동재생 차단 정책 때문이며, 웹페이지가 우회할 수 없습니다.
     교육 시작 시 아무 버튼이나 한 번 누르면 이후로는 정상 송출됩니다.
  2) 아이폰·아이패드는 본체 측면의 무음(사일런트) 스위치가 켜져 있으면
     소리가 나지 않습니다. 실물 기기 테스트 시 먼저 확인하십시오.
  3) 비화재 안내방송 / 비화재보 복구안내는 녹음 파일이 아니라 브라우저의
     한국어 음성합성으로 낭독합니다. 기기에 한국어 음성이 없으면 이 두 가지만
     소리가 나지 않습니다(경종·싸이렌·화재안내방송은 녹음 파일이라 영향 없음).

■ 음원 교체
  audio/ 폴더의 같은 이름 파일을 바꿔 넣으면 그대로 반영됩니다.
  mp3 만 넣어도 동작하며, webm 은 없어도 됩니다.
  비화재 안내방송·복구안내를 녹음 파일로 바꾸려면 index.html 안의
    const ANNOUNCE_FILES={ nonfire:"", recover:"" };
  부분에 경로를 적으면 됩니다.  예) nonfire:"audio/pa-nonfire.mp3"

■ 음량 기준
  세 음원 모두 동일한 체감 음량(-16 LUFS)으로 정규화되어 있습니다.
  화재시 안내방송만 1.15배 높게 송출되어 다른 방송과 구분됩니다.
  (index.html 의 const FIRE_GAIN=1.15 값으로 조절 가능)

■ 교육용 재현 범위
  연동 순서와 출력 범위를 재현한 교육 자료이며, 실제 설비의 지연시간·복구
  절차와는 다를 수 있습니다. 확인이 필요한 항목은 화면 하단 "확인이 필요한
  항목" 칸에 정리되어 있습니다.
